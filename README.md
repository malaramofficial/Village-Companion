# Village Companion

**गाँव में काम और सेवा आसानी से खोजें।**

Village Companion is a rural services marketplace for connecting local customers with workers, farmers, mechanics, tradespeople and agricultural machine owners.

## V1 categories
- कृषि मजदूर
- Tractor / कृषि मशीन
- Electrician
- Motor / Pump Repair
- Plumber
- Mason / Welding

## Product principle
V1 focuses on discovery and direct contact: customer finds an available local provider and calls/WhatsApp directly. Online payments and commissions are intentionally deferred until real demand is validated.

## Planned roles
- Customer
- Service Provider
- Admin
